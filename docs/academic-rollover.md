# Academic Rollover

Rollover is a data-pack workflow, not a manual database operation.

1. Copy the master pack for the institution.
2. Add the new academic year row.
3. Create new category idnumbers for the target year.
4. Create or update course rows for the new year.
5. Create cohorts and groups for promoted learners.
6. Validate and plan.
7. Dry run with operators.
8. Apply during a scheduled maintenance window.
9. Archive the import report and smoke-test tenant access.

Keep historical course categories and courses visible or archived according to institution policy; do not reuse idnumbers across academic years.
